🎯 NIC 업그레이드의 핵심 효과
1G 환경에서 NIC 사용률이 평균 28.9%, 최대 57.6%까지 올라가며 SYNCHRONOUS_COMMIT의 병목이 되고 있었습니다. 10G 전환 후 AG 복제 대역폭 제약이 해소되어 HADR 대기시간이 51.8% 감소(0.722ms → 0.348ms), TPS는 108.8% 증가했습니다.
📈 Transaction Delay 증가는 병목이 아닙니다
Transaction Delay가 457ms → 1,207ms로 증가했지만, 이는 처리량이 2배 이상 증가하면서 복제 큐가 자연스럽게 늘어난 것입니다. HADR 대기시간 자체는 감소했으므로 성능 저하가 아닌 처리량 증가의 정상적인 부산물입니다.
✅ CPU / Disk 병목 없음
10G 환경에서 CPU는 평균 18.5%로 임계값(85%) 대비 충분한 여유가 있으며, Disk I/O도 정상 범위입니다. 현재 환경에서 추가 처리량 증가 여지가 충분합니다.

결론 및 권고사항
🏆 핵심 결론
1G → 10G NIC 업그레이드는 SYNCHRONOUS_COMMIT 환경에서 매우 유의미한 성능 개선 효과를 가져왔습니다. HADR 대기시간 51.8% 감소, TPS 108.8% 증가, Batch Requests/sec 127.5% 증가가 달성되었으며, CPU/Disk 등 다른 리소스는 모두 정상 범위 내에서 동작하고 있습니다.
📌 추가 최적화 권고
• Jumbo Frame (MTU 9000) 설정으로 대용량 전송 효율 향상
• RSS/VMQ 활성화로 NIC 수신 부하 분산
• HADR 전용 NIC 분리로 일반 클라이언트 트래픽과 복제 트래픽 분리
• 25G NIC 비교 테스트로 추가 성능 한계 확인 권고
• 비동기 모드(ASYNCHRONOUS_COMMIT) 비교로 동기/비동기 트레이드오프 분석
